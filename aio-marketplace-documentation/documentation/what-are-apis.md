# What are APIs?

APIs are crucial in software development because they enable developers to add new functionalities to existing software without directly implementing them. They define the actions and operations of software, allowing programmers to leverage existing capabilities and reduce time spent on application development.

### Importance of APIs

Allow engineers to communicate with other product services, without actually writing the implementation, this help developers save time and resources. APIs are use in a wide range of application, e-commerce site, mobile applications, and desktop applications.

## REST APIs

Rest API communicates by send a message via HTTP message, similar to how an API work. The message is sent back as an JSON object letting you know what operations are available and the resources that can be used. There are certain endpoints that give back specific data when calling the certain endpoints, every endpoint is different and points to different types of data.
