# Reports

## Project Reports

When pulling an project report, you can pull from a specific timeline or by project. This allows you to see the progress % of the project. Total revenue from this project, whether this project is active or not, expenses sent on the project. Expenses combines equipment, material cost, time spent cost per employee.

### Columns

* Project %
* Revenue
* Status&#x20;
* Expenses (equipment cost, material cost, time spent cost)
* Start Date&#x20;
* Expect End Date

## Work Order Summary

This report allow you to see how many work order were given within a certain time period, the **status** of that work order, **total** work orders assigned the a specific project, how many work order an assignee **completed**, **average** completion time.

#### Filters

Entering a specific date range, will allow you pull an work order that was assigned within that time range. Also you have the ability to select an project and see the work orders from the specific project. Or even pull the work orders that were assigned to a specific worker (assignee)

Also summarizes can be exported to and PDF or excel sheet.

### Columns

* Work Order #&#x20;
* Title (Name of Work Order)
* Status&#x20;
* Assignee
* Value of Work Order
* Total Work Orders Assigned
* Total Work Orders Completed&#x20;
* Average Time Completion

## Progress Reports

Progress reports allows you to see, **total** progress reports where **completed** for an specific project, what **week** the progress report was submitted, **who** submitted it, **units** submitted and the **status** of the progress reports.

#### Filters

Progress reports can be filtered to a specific range&#x20;

### Columns

* Total progress reports
* Status
* Week
* Assignee
* Units

## Budget Utilization

This report allows you to see the budget **usage** of each project, **usage percentage**, budget **amount**, **project** name, **actual spend**.

Budget reports can be filtered to a specific time and project only.

### Columns

* Project Name
* Usage (%)
* Actual Spend
* Variance
* Variance Percentage (%)

## Vendor Performance

This report allow you to view the top performing  vendor (by favorable prices). Each vendor are carriers that we purchase material from, usually are quoted. When a project is intialized, these quote have an expire period, which can cause price increases. Whihc is why this is report is some value because it allow to see all vendors that have quoted us and make the best decision and choose the one the aligns with our margins.

### Columns

* Vendor Name
* Date
* Previous Price
* Current Price
* Status&#x20;
* Trend Percentage
