# React

React is a an framework, that modify the virtual dom in terms of components, it is in competition with other frameworks such as angular and is really popular among all frameworks. React allows you to build virtual components that in isolation update the virtual dom and other render what is needed to be render, not the entire dom what an change happens.

### Why React?

Before reach the web development was very static, you would have to create multiple pages per functionality of an component, and to render dynamic changes you would have to rerender the whole page through ajax. With react the render is much more efficient and quick especially with the new complier in reach 18 new update. Now you can build very dynamic interfaces and UI components with the structure of components.

### Components

Components are not just an react concept this is an web developer concept to that make it easier and faster to build. Components are reusable piece of code (html) that can be used thoughout your project. Can be broken down into smaller components, which helps with maintaining the structure. Components have their **state**, meaning the type of data the it currently hold and the **props** which are the argurements that components take in.

#### Props<br>

Props are short for properties similar to parameters in a regular javascript function. These are read-only and are passed in through react component.

#### State

State is an javascript object within the components that holds data and when updated re-renders some new data. State is commonly use with `useState`

### Types of Components

There are two types of components, **class base component (older)** or **functional components**. functional components are the more modernally used by most developer, but it is all just perference.
