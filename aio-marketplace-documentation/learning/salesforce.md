# Salesforce

## Salesforce Platform Basics

1. An **app** in Salesforce is an objects, fields and other functionality that supports business functions
2. **Objects** are tables Salesforce database that holds a particular information, you could have custom object that contains property.
3. **Records** are row in database that hold the actual information associated with the data.
4. **Fields** are columns in the objects database that represents properties of the information for example, address, zip code, ext...
5. **Org** is a specific instance of Salesforce, that represents a organization, each entity has its own instance of Salesforce or **org.**
