# RESTful API

## What is a RESTful API?

RESTful API is an interface that computers use to exchange information securly over the internet. Most business applications needs to get and retrieve information from other applications, RESTful API allows us to do so securly, using formatting and communication standards.

#### What is API?

An API (Application Programming Interface) are defined rules that allow the client to request information and to retrieve information from other software. The API processes this information format it, then send this information to the client or resources.
