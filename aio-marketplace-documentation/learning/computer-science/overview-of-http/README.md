# Overview of HTTP

When you access a website's information or send a **HTTP request** to a site the **web server** typically search for a host of the page. If no page is found, the web server searches for home page of your directory `index.html` . Then it send back resource in an object **HTTP response**, this include like the type of resources, the resource's length and other information.

<figure><img src="../../../.gitbook/assets/image (8).png" alt=""><figcaption><p>Picture of an HTTP Request &#x26; Response</p></figcaption></figure>

This allow us to send data, such as images, website information, text, and videos seamlessly.

## Uniform Resource Locator: URL

URL is the most popular way of finding resources about your website and can be broken into three categories&#x20;

* **Scheme**, which is the protocol for the website for example `https://` or `http://` , one is secure and the other is not
* **URL** , the actually domain name of the URL, which is used to access the website for example `www.ibm.com` or `www.google.com`&#x20;
* Route: the location of the web server for example `"/images/hero.png"`&#x20;

You may commonly hear **URI** (Uniform Resource Identifier), which is just a subset of URL and also the term called **endpoint.** This is an operation done on the URL.
