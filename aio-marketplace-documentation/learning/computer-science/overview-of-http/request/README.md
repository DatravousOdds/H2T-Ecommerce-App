## Response

After sending a request you should receive an response back from the website that you are trying to access, typically there is an start line that include the HTTP version `HTTP/1.0` , status code indicating whether the request was success and then some descriptive text. There is also an request header that include useful information, then lastly the request body that are turn file you are requesting in HTML format.
